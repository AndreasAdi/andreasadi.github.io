I am Andreas Adi Purwanto, a software developer. I build web applications for
small businesses, desktop tools for Linux, and small apps for the people around
me.

Most of my day-to-day work is PHP and Laravel with MySQL on the back end, and
TypeScript, Flutter, or QML when a desktop or mobile client needs building. I
run Omarchy on my laptop and like boring tools that do one thing well.

This site is hand-built: a small Node script turns Markdown into HTML and GitHub
Pages serves the result. There is no framework, no database, and no JavaScript
in the pages themselves.

You can find me on [GitHub](https://github.com/AndreasAdi) or by
[email](mailto:andreas@andreasadi.xyz).
